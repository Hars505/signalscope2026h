## Reproducing the local proxy evaluation

```bash
cd "Frontend&Backend/app/backend"
python manage.py migrate
python ml/evaluate_ensemble.py \
  "../../../ModelsP2/data/parveshiiii_subset/processed/test.csv" \
  --output "../../../ModelsP2/report/ensemble_parveshiiii_proxy_metrics.json"
```

The organizer-held-out score must be generated by running the same prediction
interface against the organizer's private manifest. It must not be replaced
with the local Hemg or Parveshiiii score.
